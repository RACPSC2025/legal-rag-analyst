📋 Instrucciones para el usuario:

Si ves "ERR_CONNECTION_REFUSED" en el navegador, prueba lo siguiente:

  1. Verifica que el servidor está ejecutándose (deberías ver logs en la terminal)
  2. Prueba en modo incógnito (Ctrl+Shift+N) para evitar extensiones que bloqueen
  3. Verifica el firewall de Windows:
    • Abre "Firewall de Windows Defender"
    • Ve a "Configuración avanzada"
    • Verifica que hay reglas para Python o uvicorn
  4. Prueba con otro navegador (Chrome, Firefox, Edge)
  5. Verifica que no hay proxy configurado:
    • Configuración de Windows → Red e Internet → Proxy
    • Desactiva "Usar script de configuración"

🛠️ Soluciones comunes:

1. Problema: Firewall bloquea Python

Solución: Crear regla de firewall para Python

New-NetFirewallRule -DisplayName "Python Development" -Direction Inbound -Program "$env:USERPROFILE\.venv\Scripts\python.exe" -Action Allow

2. Problema: Proxy bloquea localhost

Solución: Añadir localhost a lista de excepciones

netsh winhttp set proxy bypass-list="<local>;127.0.0.1;localhost"

3. Problema: Puerto 8000 ocupado

Solución: Cambiar puerto en la API

uvicorn api.main:app --reload --host 127.0.0.1 --port 8001
